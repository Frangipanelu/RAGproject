## 三、实现路径详解

### 📝 路径1：文档上传与知识库构建

```
用户上传文件 → 解析文本 → 文本分割 → 向量化 → 存储到Chroma
```

**核心流程 (app_main.py → knowledge_base.py)**：

1. **文件上传** (`render_uploader_page`)：
   - 支持格式：md、pdf、docx
   - 文件保存到 `data/uploads/<类型>/` 目录
   - 自动处理重名文件（追加序号）

2. **文本提取** (`extract_text`)：
   - MD：直接解码UTF-8
   - PDF：使用 `pypdf.PdfReader` 提取
   - DOCX：使用 `python-docx` 提取

3. **知识库入库** (`KnowledgeBaseService.upload_by_str`)：
   ```python
   # 1. MD5去重检查
   md5_hex = get_string_md5(data)
   if check_md5(md5_hex):
       return "[跳过]内容已经存在知识库中"
   
   # 2. 文本分割（超过1000字符）
   if len(data) > 1000:
       knowledge_chunks = spliter.split_text(data)
   
   # 3. 向量化并存储
   self.chroma.add_texts(knowledge_chunks, metadatas=[metadata])
   ```

---

### 🔍 路径2：检索问答流程

```
用户提问 → 向量检索 → 构建Prompt → LLM生成 → 返回结果
```

**核心流程 (app_main.py → rag.py → vector_stores.py)**：

1. **检索链构建** (`RagService.__get_chain`)：
   ```python
   chain = (
       {
           "input": RunnablePassthrough(),  # 用户输入透传
           "context": RunnableLambda(format_for_retriever)  # 格式化查询
                    | RunnableLambda(retrieve_with_retry)   # 向量检索（带重试）
                    | format_document                       # 格式化文档
       } 
       | RunnableLambda(format_for_prompt_template)  # 构建prompt模板输入
       | self.prompt_template                        # 提示词模板
       | self.chat_model                             # 通义千问模型
       | StrOutputParser()                           # 输出解析
   )
   ```

2. **带记忆的对话** (`RunnableWithMessageHistory`)：
   - 使用 `FileChatMessageHistory` 持久化对话历史
   - 自动维护 `session_id` 对应的对话上下文

3. **系统提示词设计**：
   ```
   你是一名资深职业规划专家、招聘专家+HRBP、简历优化专家。
   能力：JD解析、简历优化、职业建议
   ```

## 六、关键设计亮点

1. **MD5去重机制**：避免重复上传相同内容
2. **网络重试逻辑**：`retry_on_error` 装饰器处理API调用失败
3. **会话持久化**：基于文件的对话历史存储
4. **职业规划专家角色**：系统提示词专注于求职场景
